# Канск Сегодня — публичная система публикации

Открытая веб-страница и облачный исполнитель команд для единственного Telegram-канала `@kansk_segodnya`. Общий доступ без входа, пароля, API-ключа клиента и обязательного плагина включён по прямому поручению владельца канала. Любой посетитель может публиковать и редактировать сообщения в этом канале.

- Сайт на GitHub Pages: https://ivanhhgdx.github.io/kansk-segodnya-publisher/
- Облачная версия и сервер: https://edit-kansk-publisher.ivanfomin2003.chatgpt.site
- Инструкция для агента и схемы всех команд: https://edit-kansk-publisher.ivanfomin2003.chatgpt.site/api/command
- Исходники: https://github.com/Ivanhhgdx/kansk-segodnya-publisher

## Как пользоваться

Открыть страницу, выбрать действие, заполнить поля и отправить команду. Для проверки соединения есть отдельная кнопка, которая не публикует постов.

Агент может работать через ту же страницу либо посылать HTTPS-запросы к серверу:

```http
POST /api/command
Content-Type: application/json

{"action":"telegram_check_connection","arguments":{}}
```

Авторизация не нужна. Сервер возвращает `{"ok":true,"result":...}` либо `{"ok":false,"error":"..."}`. Все команды и JSON-схемы параметров доступны обычным GET-запросом по этому же адресу. Разрешён CORS для браузерных клиентов.

Команды: `telegram_check_connection`, `telegram_list_operations`, `telegram_get_operation`, `telegram_publish_text`, `telegram_publish_media`, `telegram_edit_text`, `telegram_edit_caption`, `telegram_edit_media`.

MCP `/mcp` сохранён как дополнительный интерфейс, но не требуется для работы сайта или HTTP-команд.

## Сохранение результата

Перед отправкой и правкой проверяются бот, канал и права. ID бота `9166835869`, username `kansk_segodnya_editor_bot`, ID канала `-1004489066922`. Другие каналы и произвольные методы Bot API не принимаются.

Каждой публикации и правке нужен уникальный `operation_key`. Он сохраняется в общей облачной D1-базе. Повтор того же завершённого запроса возвращает прежние номер и ссылку поста. Другой текст с прежним ключом отклоняется. Одновременные запросы резервируют только одну операцию.

После тайм-аута сначала вызвать `telegram_get_operation` с прежним ключом. `pending` или `uncertain` нельзя повторять под новым ключом до выяснения результата в канале. Telegram не позволяет надёжно установить результат отправки после потери ответа, поэтому такие операции автоматически не повторяются. Журнал не зависит от запуска браузера или Mac.

## Ограничения

Фото и видео передаются прямой внешней HTTPS-ссылкой на файл или Telegram `file_id`. Локальные пути, альбомы и загрузка файлов с диска не поддерживаются. Максимум текста — 4096 символов, подписи — 1024; применяется дополнительная проверка Telegram. Доступны обычный текст и HTML. Удаление и расписание не добавлены.

Дополнительные тестовые публикации для проверки подключения запрещены владельцем. При проверке не создавать постов и не использовать существующие посты для пробной правки. Полная живая проверка редактирования пока не подтверждена.

GitHub Pages исполняет только браузерную часть. Команды выполняет Cloudflare Worker, размещённый через Sites. Токен бота хранится только как серверный секрет `TELEGRAM_BOT_TOKEN`; в репозитории, браузерной сборке и ответах API его нет. Локальная копия ключа остаётся в Keychain Mac. Для работы размещённой системы Mac не нужен.

Если среда агента не разрешает доступ к домену сервера, требуется штатное разрешение платформы. Публикация сайта не меняет сетевую политику чужого исполнителя и не гарантирует, что любой виртуальный компьютер сможет обратиться к нему.

## Разработка и размещение

Node.js 22.13+, для автономных тестов с `node:sqlite` — Node.js 22.13+ с поддержкой этого встроенного модуля.

```sh
npm ci
npx tsc --noEmit
node --test tests/*.test.mjs
npm run build:pages
npm run dev
```

`app/dashboard.tsx` — единый интерфейс обеих веб-версий; `github-pages/main.tsx` собирает его для GitHub Pages в `docs/`. Pages публикует `main:/docs`. `lib/telegram.ts` выполняет официальный Bot API и ведёт журнал, `lib/dispatch.ts` проверяет параметры команд, `app/api/command/route.ts` обслуживает открытый HTTP API. D1-миграции лежат в `drizzle/`.

Облачная сборка и публикация используют Sites workflow и `.openai/hosting.json`. Не создавать новый Site для обновлений; сохранять существующие project_id и D1. Секреты настраивать штатными средствами размещения и не добавлять в Git.
